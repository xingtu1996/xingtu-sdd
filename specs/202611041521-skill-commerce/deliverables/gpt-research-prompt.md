请分五部分输出，每个结论都要给来源链接和检索日期，标注【确认】【传闻】【已过时】三档置信度：

一、WorkBuddy 开放平台（open.workbuddy.cn）付费技能市场
1. 已上架付费技能的实际售价分布（抽样 20 个，列出名称/定价/买断还是订阅/评价数）

3. 审核的常见驳回原因、个人认证的具体材料要求、微信签约细节
4. 服务费 1% 是内测价还是会涨？官方文档原文在哪

二、小红书 RedSkill 最新状态
1. 是否仍为邀请制？内测范围有没有扩大？粉丝门槛（1000 粉/注册 6 个月）是否仍有效
2. 是否已支持站内付费？还是仍靠「笔记挂载→私域交易」
3. 找 5 个最新案例：谁在卖、卖什么、价格、笔记曝光与 Skill 使用数

3. caveman、ponytail 这类「沟通压缩/极简方案」技能在生态里的安装量头部数据，验证这个品类的天花板

五、GitHub 技能仓的 SEO/GEO 实证
1. 找 3 个靠 GitHub 仓库获得大量自然流量/收入的技能仓（对标中文或英文均可），分析它们的 README 结构、命名、topics、分发动作

输出为结构化中文报告，宁缺毋滥：查不到实锤的写「未找到公开数据」，禁止编造数字。最后给一页「对我方 138 技能仓的 5 条可执行建议」。

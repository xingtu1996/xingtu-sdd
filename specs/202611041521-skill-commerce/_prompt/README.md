## 写法

- **逐字，不改写**。原始提示词/邮件/群聊照录，错字也保留；需要归纳的写进 `01_analysis`，不要写在这里。
- **一源一文件**。一封邮件一个文件，一场会议一个文件；不要把不同来源揉进一个。
- **标密级**。`内部` / `敏感` / `可对外`；敏感件不进会推的仓。
- **对应产出**填文件名或 AC 编号，说明这段输入支撑了哪个结论。

## 不放进这里

- 你自己写的分析、总结、判断 → 那是 `_work/` 或正文
- 已定稿的对外材料 → `deliverables/`
- 大体积原始数据（录音/视频）→ 原处留路径指针即可，不搬进来

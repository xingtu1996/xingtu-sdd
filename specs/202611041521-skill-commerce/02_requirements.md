## 一、用户故事

- 作为 boss，我希望技能资产能自动产生收入，以便沉淀的方法论变成「数字资产复利」而不是纯投入
- 作为 boss，我希望公开仓在搜索引擎/AI 引擎/Agent 目录三层都可被发现，以便不依赖单一市场分发
- 作为潜在用户，我希望一眼看懂某个技能解决我什么问题、怎么安装，以便 5 分钟内决定是否使用/购买

## 四、非功能需求

- **兼容性**：改造不得破坏本地四池既有引用（守卫链 15 处品牌词技能改名需同步）
- **幂等性**：上架/登记动作可重复执行不重复建品
- **身份安全**：所有平台注册、收款、提现信息与雇主身份物理隔离（SAF-010 延伸）

## 五、安全条件（必填）

| 条件 | 说明 | 具体措施 |
|------|------|---------|
| **退出条件** | 单技能改造 ≤ 半天；审核 2 轮不过换下一个；30 天零收入进入策略复盘而非加码 | 记入 execution-log |
| **幂等条件** | 上架以平台唯一资产 ID 为准 | 建品前查重 |
| **回滚条件** | 公开仓改动 git revert；平台资产下架；付费方式错误=不可逆 → 定价必须 spec 留痕后再操作 | 每次发布前 dry-run 清单 |

# 可复用片段库（Copy Points）

> 与 case-studies 互补：case.md 记「怎么做的」，本库存「能直接抄的话」。
> 来源：行途技术 SDD 实战沉淀，脱敏后入库。新 spec 开工前 `sdd recall <关键词>` 先搜这里，避免重造金句/话术。
> 维护：每完成一个 spec，把该 spec 里沉淀的可复用表达补到对应分类下，带出处 case 编号。

## 一、对抗失控 / 模型控制类（SDD 内核话术）

- 「完成判定查凭证，不问模型」——模型把没做的事说成做了是高频幻觉。
- 「验收认磁盘不认自述」——子 agent 说做完了不算，`ls`/`grep`/实跑工具才算。
- 「交叉验证用脚本，不用 LLM 法官」——既省一轮 token，又免法官自己引入新幻觉。
- 「定位用原文片段，不用行号」——行号会漂移，grep 片段才稳。
- 「待拍板必须带默认值，不占决策人带宽」——禁开放式问题。

## 二、流程方法论类

- 「No Spec, No Code / Spec is Truth / Reverse Sync」三铁律（见 laws.md）。
- 「深度裁减」：单文件 Bug 走轻量 2 文件，架构改造才上重量全量——**不为了仪式感跑全程**。
- 「有引擎用引擎，不手搓目录」。

### 二·补 · 清理 / 保全类（源自 009）

- 「审计对象比动作大一圈」——已发生的动作自查，**即将执行的**动作提前备证（009）
- 「把安全性编码进工具」——能用只作用于空目录的工具，就不必靠检查兜底（009）
- 「无副本 ≠ 孤本」——快照/归档**按定义**没有副本，应单列一档，不要一律当危险（009）
- 「备份层 ≠ 存档层」——「已进真源库」≠「已进版本历史」；清理前先看未提交改动（009）
- 「**登记层 = 判定层**」——先查台账，命中即「有主的产出」、0 命中即「非产出资产」；**省掉逐个开箱**（009）
- 「先查登记层，再开内容层」——登记层筛掉大多数，内容层只查筛剩的少数（009）
- 「迁移尾气的判据是『活体库同名目录非空』」——命中即正常残留，不必回滚（009）
- 「**动作 ≠ 期望**」——「清了空目录」会被误当成「治理好了」；先显式化期望，再逐条对账（009）
- 「**真问题常在工序，不在文件**」——本例文件有 3 份副本安然无恙，断的是「生成了 → 入库了」这一段（009）
- 「**『唯一』必须实测**」——并列于上面的反例：凭「文件名没搜到」就断言全机唯一，实测有 3 份 md5 相同的副本。**排除规则（如跳过备份目录）会造出假独本**（009）
- 「**自动生成 ≠ 幂等**」——重跑生成器前先在沙箱比对 ID/键的稳定性；键不稳定 + 状态层按键存取 = **重跑即错配**（009）

## 三、红队 / 审查类

- 五类靶：引用证伪 / 单一信号绑架 / 平行系统 / 口径污染 / 副本腐烂。
- 「Filter 只减不增」——拦截 30-50% 低质量发现，减轻人审负担。
- 「红队只攻击只做减法，不处置」——成立与否归主会话。

## 四、跨工具/跨会话续传类

- 「收尾即留痕：会话随时被切走，每个阶段落盘，下个会话靠文件接续不靠记忆」。
- 「recap 再动手：三五行讲清要解决什么/已做到哪/挂着什么待拍板」。
